# 🎬 Day 4 — Python Quiz

A simple command-line quiz with **Movies and Math** categories.

## Features

- Choose between Movies or Math quiz
- Randomizes question order
- Multiple-choice questions
- Input validation
- Score tracking
- Play again option
- Reusable quiz function

## Concepts Practiced

- Lists & dictionaries
- Functions
- `for` loops
- `while` loops
- `if/elif/else`
- `enumerate()`
- String methods
- `random.shuffle()`
- User input & validation

## How to Run

```bash
python main.py
```

## What I Learned

I learned how to reduce duplicate code by creating a reusable function that can handle different quiz categories.
